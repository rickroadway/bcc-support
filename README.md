# BCC public support website

Public support and privacy information for BCC Business Command Center, provided by Richard Crawford.

Static pages only. No application source, credentials, customer records, forms, analytics or client-side JavaScript are included. Contact: rickroadway@gmail.com.

## Publish with GitHub Pages

Repository Settings → Pages → Deploy from a branch → main → /(root) → Save.

After GitHub reports a successful deployment, verify the homepage and the /support/ and /privacy/ routes without signing in. GitHub Pages serves these pages under the repository path; all asset and page links are relative. The expected URLs are not proof of deployment:

- https://rickroadway.github.io/bcc-support/
- https://rickroadway.github.io/bcc-support/support/
- https://rickroadway.github.io/bcc-support/privacy/

The app is currently in TestFlight. Planned launch price: US$9.99 once. This site does not offer a purchase or imply the app is publicly available. App Store pricing and submission remain separate.

GitHub hosts this website and may process visitor access information under its own policies. No BCC business records are collected by the website. The privacy page separately describes the iPhone app and email support.
